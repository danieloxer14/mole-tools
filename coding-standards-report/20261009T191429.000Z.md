#### `no-nested-ternaries` — MUST — fixed

- **Location:** `src/adapters/git-host/gh.ts:602-609`
- **Structure:** `GhAdapter.fetchMr`
- **Why:** Nested ternary obscured precedence in pull-request state mapping; explicit branches make merged/open/closed behavior clear.
- **Before**

```typescript
state:
    pull.merged_at !== null
        ? "merged"
        : pull.state === "open"
            ? "opened"
            : "closed",
```

- **After**

```typescript
let state: string;
if (pull.merged_at !== null) {
    state = "merged";
} else if (pull.state === "open") {
    state = "opened";
} else {
    state = "closed";
}
```
