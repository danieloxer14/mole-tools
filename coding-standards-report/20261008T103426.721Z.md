### Proposed rules (report-only)

#### `parameterized-tests` — SHOULD — match

**Location:** `src/features/review/layers.test.ts:349-436`  
**Structure:** `describe > test('selects mode- and preset-specific layer prompts')`  
**Why:** One prompt-selection behavior is exercised for plan/code modes and default/terse presets; separate parameterized cases could report the failing combination directly.

**Before:**
```ts
await savePrompt("review-layers-code", {
	preset: "default",
	text: "DEFAULT CODE LAYERS PROMPT",
	dir: promptDir,
});
await savePrompt("review-layers-plan", {
	preset: "default",
	text: "DEFAULT PLAN LAYERS PROMPT",
	dir: promptDir,
});
await savePrompt("review-layers-code", {
	preset: "terse",
	text: "TERSE CODE LAYERS PROMPT",
	dir: promptDir,
});
await savePrompt("review-layers-plan", {
	preset: "terse",
	text: "TERSE PLAN LAYERS PROMPT",
	dir: promptDir,
});
```

**After (suggestion only):**
```ts
const layerPromptCases = [
	{ mode: "plan", preset: "default", expected: "PLAN LAYERS PROMPT" },
	{ mode: "plan", preset: "terse", expected: "TERSE PLAN LAYERS PROMPT" },
	{ mode: "code", preset: "default", expected: "CODE LAYERS PROMPT" },
	{ mode: "code", preset: "terse", expected: "TERSE CODE LAYERS PROMPT" },
] as const;
```
Use these rows with `test.each`, retaining one isolated generation and its
expected-prompt assertions per row.
